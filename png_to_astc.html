Déjalo desactivado. El .astc se guarda automáticamente de pie, igual que las texturas originales de FNF Android, y la vista previa siempre se muestra de pie. Actívalo solo si tu PNG de origen está volteado.
💡 ¿Por qué el ASTC puede pesar más que el PNG? ASTC usa 16 bytes por bloque, aunque el bloque esté vacío: no comprime la transparencia como el PNG. Para que pese poco: sube el XML y deja activado 📦 Reempaquetar atlas (quita el espacio vacío y los frames repetidos), y si aún pesa mucho reduce la escala en lugar de usar bloques de 10×10 o 12×12 (esos ensucian los bordes del personaje). Descarga: solo PNG → un archivo .astc. Con XML (y JSON) → un .zip con el .astc, el XML nuevo, el JSON ajustado y un informe .txt de qué cambió y qué sigue igual. Usa siempre esos archivos juntos.
